## Intent

Give every project a stable, unique, filesystem-safe `slug`, and provide a
helper computing the per-project app-config directory
`<config-root>/projects/<slug>/`. This is plumbing for the workflows system
(D1/D6 in `docs/specs/workflows-system-decisions.md`): workflow definitions
and profiles will live under that directory in M1. No UI, no consumers wired
in this packet.

## Design decisions (binding)

- **Migration (next version, append-only):** add `slug TEXT NOT NULL DEFAULT
  ''` to `projects`, backfill every row, then create a UNIQUE index on
  `slug` (name it per existing index conventions). Follow the existing
  migration-struct pattern for Go-side data fixups if one exists; otherwise
  match how neighboring migrations do data work. Update any
  migration-count/test assertion the conventions require.
- **Slugify rules:** lowercase; every run of characters outside `[a-z0-9]`
  becomes a single `-`; trim leading/trailing dashes; cap at 64 chars
  (re-trim after capping); empty result falls back to `project`.
- **Uniqueness:** collisions get `-2`, `-3`, … suffixes (suffix may push past
  the cap — trim the base, not the suffix). Backfill is deterministic:
  process rows ordered by `created_at, id`.
- **Single-sourced slugifier:** exactly one function generates slugs, used by
  both the migration backfill and every project-insert path. Placement is
  your call (no import cycles) — state the rationale in the report.
- **Creation chokepoint:** find every path that inserts a project row (e.g.
  `CreateProject`, workspace-ensure paths) and make each assign a unique slug
  at insert. **Slug is immutable:** renames and updates never rewrite it; no
  update statement may touch the column.
- **Struct + bindings:** `Project` gains `Slug string` with json tag `slug`.
  Regenerate the TS bindings with the same invocation `build/Taskfile.yml`
  uses (`wails3 generate bindings -clean=true -ts`; the `wails3` tool comes
  from the go.mod tool directive — `go install tool` if missing). The diff
  under `frontend/bindings/` must contain only the generated slug additions;
  paste `git diff --stat frontend/bindings` into the report.
- **Config-dir helper:** in `internal/project`, add pure helpers — one
  returning `<configRoot>/projects/<slug>` from explicit args (no globals),
  and one that also `MkdirAll`s it, returning the error (never swallowed).
  Do NOT wire any callers; M1 consumes this.
- **Docs:** update `docs/architecture/schema.md` — add `slug` to the projects
  table docs (unique, immutable, filesystem-safe; what it's for). ALSO fix
  the stale pointer at the top of that file: it claims migrations live in
  `internal/store/migrations/`, but they live in `internal/store/migrate.go`.
