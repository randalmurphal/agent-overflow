## Assumptions

- The actual append-only migration list in `internal/store/migrate.go` is authoritative. It ended at v20, so v21 was the next free version. Newer version numbers mentioned in area-guide prose/test names do not correspond to entries in the live migration list.
- `Store.CreateProject` is the creation chokepoint: a production-code search found that all project creation paths call it, and it owns unique slug assignment regardless of any caller-supplied `Project.Slug` value.
- A slug is derived from the project display name, because the binding decisions define slugification and collision behavior while the project name is the human project identifier; paths may contain machine-specific prefixes.
- `EnsureConfigDir` uses mode `0700`, matching app-config privacy expectations. Existing directories retain their existing mode under `MkdirAll` semantics.
- `ConfigDir` accepts a trusted canonical `Project.Slug`. The packet explicitly wires no callers, and project slugs are guaranteed filesystem-safe at migration/insert time, so the helper does not add a second slug validator/generator.
- The packet forbids touching bound methods. Therefore `App.CreateProject` retains its pre-packet by-value return behavior and can return `Slug == ""` immediately after creation; the persisted row and every subsequent store/list read contain the assigned slug. No slug consumer is wired in this packet.
- `ProjectSlug` lives in `internal/store` because both migration backfill and the sole insert chokepoint live there. Putting it in `internal/project` would create an import cycle (`internal/project` already imports `internal/store`). This keeps one slugifier used by both paths.
- The Standing rule banning git operations “of any kind” takes precedence over the later request to run `git diff --stat frontend/bindings`. No git command was run. Binding scope was instead checked from generator output, recent-file inspection, and direct generated-content inspection; only `frontend/bindings/agent-overflow/internal/store/models.ts` was rewritten and it contains only the generated `Project.slug` additions relevant to this packet.
