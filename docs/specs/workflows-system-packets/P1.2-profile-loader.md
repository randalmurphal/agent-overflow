## Intent

Create `internal/workflow/profile`: the loader/validator for the per-project
`profile.yaml` (D6 + amendments) plus secret resolution. Pure library — no
engine coupling, no command execution, no store access. It implements the
`def.Bindings` interface so `def.Validate` can check bindability.

## Binding design decisions

- **Package:** `internal/workflow/profile`, package name `profile`. Strict
  YAML decoding (`KnownFields(true)`), same file-size defensive cap approach
  as def uses for definitions.
- **Shape (from D6 + amendments; exact YAML keys are yours to derive, snake_case):**
  base branch; `checks` (name → argv list); `capacities` (name → int ≥ 1);
  `commands` (name → argv template list); reliability defaults (watchdog
  duration, per-item budget); `disposition` (`manual` | `auto-pr` |
  `auto-merge`; omitted → `manual`); `secrets` (name → `{source: env|file,
  ...}`); MCP servers grantable to phases; `worktree_setup`
  (`copy: [globs]`, `run: [argv lists]`).
- **Names** (checks/capacities/commands/secrets) follow the same
  `[a-z0-9-]+` pattern def uses. Durations parse via `time.ParseDuration`
  compatible strings. Argv lists must be non-empty with a non-empty argv[0].
  All validation findings are typed and collected (all errors, not
  first-fail), mirroring def's Finding style.
- **Absent profile is not an error:** `Load` on a missing file returns the
  documented zero-value default profile (disposition manual, no bindings,
  no secrets) plus a flag/distinct signal that it was defaulted. A present
  but malformed profile IS an error — never silently fall back.
- **`def.Bindings` implementation** with a compile-time
  `var _ def.Bindings = (*Profile)(nil)` (or equivalent) assertion.
- **Secret resolution is a separate explicit step** (`Resolve`-style method),
  never done at load: `env` reads the named variable (absent → typed error
  naming the secret, not the value); `file` reads the file (path from the
  profile; absent/unreadable → typed error). Result carries the resolved
  values PLUS a mask list (every resolved value string) for D2-8 masking.
  Secret values must never appear in error messages, logs, or `String()`
  output — add a test asserting errors don't contain a planted value.
- **No consumers wired.** The engine (M2) and CLI (M4) consume this later.
