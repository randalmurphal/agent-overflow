# Hack Nerd Font

These woff2 files are sliced from the upstream `Hack.tar.xz` shipped
with the Nerd Fonts project. The unpatched Hack typeface is by Source
Foundry; the Nerd Fonts project patches it with extra icon glyphs in
the Private Use Area.

## Source

- Project: https://github.com/ryanoasis/nerd-fonts
- Release: v3.4.0
- Archive: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/Hack.tar.xz
- Variant: `HackNerdFont-*` (proportional-icon, mono Latin) — *not*
  `HackNerdFontMono-*` (single-width icons) and *not*
  `HackNerdFontPropo-*` (fully proportional Latin).

## Slicing

Each face is split by `slice_fonts.py` into five unicode-range loading
units (`text`, `symbols`, `powerline`, `icons`, `icons2`) so the
browser fetches — and pays decoded-sfnt renderer memory for — only the
glyph ranges a session actually renders. A monolithic face decodes to
~2.7 MB; a plain-ASCII terminal session under the sliced set loads the
`text` slice at a fraction of that (measured 2026-07-21, renderer
`web_cache/Font_resources`).

No glyph is dropped: the slices partition the full Nerd Font cmap, the
script verifies outline + advance-width fidelity for every sliced
codepoint against the original, and a codepoint outside every
unicode-range falls through the font stack exactly as a cmap miss
always has. `src/lib/utils/hack-nerd.css` is generated by the same
script so the declared ranges can never drift from the slice contents.

Two knowingly-accepted subsetting artifacts:

- The FontForge-private `PfEd` table is dropped (fontTools cannot
  subset it; it carries editor metadata, nothing renderable).
- A slice's cmap may include a few extra entries for glyphs pulled in
  by closure (shared outlines / GSUB alternates). They are unreachable
  — unicode-range gates face selection and each extra's range entry
  lives in its home slice — and the script verifies they map to the
  same glyph as the original.

## Refreshing

To pull a newer Nerd Fonts release:

1. Download the matching `Hack.tar.xz` from the Nerd Fonts releases
   page and extract `HackNerdFont-{Regular,Bold,Italic,BoldItalic}.ttf`
   into a scratch directory.
2. Set up the tooling:

   ```sh
   python3 -m venv /tmp/fontenv
   /tmp/fontenv/bin/pip install fonttools brotli
   ```

3. Run the slicer (it writes the woff2 slices next to itself and
   regenerates `src/lib/utils/hack-nerd.css`):

   ```sh
   /tmp/fontenv/bin/python slice_fonts.py <scratch-dir>
   ```

4. Review the script's coverage-variance notes, update the version pin
   recorded above, and delete any slice files a boundary change
   orphaned (`git status` shows them as modified-but-unreferenced).
5. Re-run `pnpm run build` and confirm the emitted CSS chunk still
   references every slice.
